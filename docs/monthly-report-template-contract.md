## 页面与格式系统

- 纸张：A4。
- v1 第 1、2、4 节为纵向，附件第 3 节为横向；v2 删除附件后应仅剩 3 个纵向分节。
- 纵向页边距：上/下 1.00 英寸，左/右 1.25 英寸。
- 主标题：方正小标宋简体、26pt、红色、居中、固定值 28pt。
- 期号：楷体_GB2312、16pt、加粗、居中。
- “本期要目”：黑体、18pt、居中。
- 要目栏目标签：黑体、16pt。
- 正文：仿宋_GB2312、16pt、固定值 28pt、首行缩进约 32pt、段后约 5pt。
- 一级标题：黑体、16pt；二级标题：楷体_GB2312、16pt、加粗。
- 模板没有使用 Word Heading 样式，格式主要是直接格式；程序不得用通用样式重建全文。

## Agent 提示语规则

- `【栏目定位】`、`【内容来源】`、`【写作格式】`、`【预期内容】`、`【案例选取原则】` 均作为栏目 `writingGuide`。
- Agent 分析和月报草稿阶段可以读取这些提示。
- Word 生成阶段禁止调用 LLM，并必须删除这些提示段落。
- 正式成稿若残留提示语或任何 `{{...}}` 占位符，生成必须失败。

## 保真边界

- 只允许修改 `word/document.xml` 中的明确插槽、提示段落和用户确认删除的附件范围。
- `styles.xml`、`numbering.xml`、页脚、PAGE 域、关系文件、绘图、横线和主题均为保留项。
- v2 允许的结构变化仅为删除附件表/横向分节和增加先锋栏目插槽。
- 每次模板修改后必须检查分节、表格数、占位符、包部件差异，并使用 Microsoft Word 渲染全部页面。
